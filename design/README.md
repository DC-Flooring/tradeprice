# Design reference

Reference files for rebuilding the trade site home screen. Not served as part of the site.

- `Home.dc.html`: the approved home screen design (canvas template format; data for the `<sc-for>` loops is in the script at the bottom, `{{accent}}` is #B8924A).
- `home-screenshot.png`: full-page render of that design at 390px wide. Barlow and Inter fell back to system fonts in this render, so numbers and body text look slightly different from the intended fonts.
- `dc-logo.png`: DC Flooring logo with a transparent background.
- `singel-regular.otf`: Singel Regular, Fontspring demo (mockups only, needs a web licence before launch). Singel SemiBold demo is also at the repo root.
- `auttera.woff2`: Auttera, for the hand-written accents only.
